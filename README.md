# ValoirTech Portfolio

A modern glassmorphism-inspired developer portfolio built with responsive UI, animated branding, and a premium multi-color identity system.

---

## ✨ Features

- Glassmorphism UI design
- Responsive mobile-first layout
- Animated floating logo system
- Dark / Light mode support
- Smooth scroll & reveal animations
- Project filtering system
- Modern hero section
- Floating glass buttons
- PWA-ready favicon pack
- Apple-style translucent UI panels
- Animated orbit/glow effects

---

# 🖥️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Glassmorphism Design System
- Responsive CSS Grid/Flexbox

# 🚀 Running Locally

## Option 1 — Simple Local Run

Open `index.html` directly in your browser.

## Option 2 — VS Code Live Server

1. Install the Live Server extension
2. Right click `index.html`
3. Select “Open with Live Server”
